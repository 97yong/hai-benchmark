학습 비율 대비 성능

    파라미터 대비 성능

      제출하기

      submit.py 한 파일이면 됩니다. 채점은 각자 컴퓨터에서 돌아가고 지표만 올라갑니다.

      gh auth login     처음 한 번만

python3 submit.py 홍길동 "CNN2D w48" pred_*.csv \
    --input STFT --ckpt model.pt \
    --preprocess "창별 RMS 정규화 · STFT n256/h128" \
    --arch "CNN2D 5블록 · width 48" \
    --loss CrossEntropy --optim "AdamW · OneCycle" \
    --epochs 8 --batch 128 --lr 3e-4

      row,pred 두 열이면 됩니다. 전처리·구조·학습 설정을 같이 주면 리더보드에서 행을 눌러 펼쳐 볼 수 있습니다. 사전학습을 했다면 --pretrain, 예측 전에 타깃 데이터로 적응한다면 --adapt 를 붙이면 배지가 달립니다. 사용법 자세히 보기

      Few-shot 세션

      학습 데이터가 적을 때 얼마나 버티는지 재는 학습 곡선 세션입니다. 시험셋은 다섯 조건 모두 Time 과 똑같고(1,331 주행), 학습량만 줄입니다. 1% ⊂ 2% ⊂ 5% ⊂ 10% ⊂ 20% 로 포함 관계라 점 사이 차이가 학습량 때문임이 보장됩니다.

      python3 submit.py 홍길동 "CNN2D w48" pred.csv \
    --split time_sub05     학습 5% 조건

time_sub01  400창    time_sub02  794창
time_sub05  1,986창  time_sub10  3,975창
time_sub20  7,951창  (전량 39,761창)

      시험셋 행이 Time 과 같아 자동 판별이 안 되므로 --split 이 필요합니다. 파일명에 time_sub05 가 들어 있으면 생략해도 됩니다. 다섯 조건을 다 내면 그래프에 곡선이 완성됩니다.

      채점 규약

      순위
      고른 세션에 속한 분할의 평균으로 매깁니다. 일반화 세션은 네 시나리오, Few-shot 세션은 다섯 비율입니다.
      집계
      창 단위로 내면 채점기가 주행 단위 다수결로 묶습니다.
      FNR
      고장을 정상이라 놓친 주행 비율(%). 안전상 가장 위험한 오류입니다.
      FPR
      정상을 고장이라 부른 주행 비율(%).
      FNR+FPR
      두 오류를 더한 값. 낮을수록 좋습니다.
