파라미터 대비 성능

    제출하기

    submit.py 한 파일이면 됩니다. 채점은 각자 컴퓨터에서 돌아가고 지표만 올라갑니다.

    gh auth login     처음 한 번만

python3 submit.py 홍길동 "CNN2D w48" pred_*.csv \
    --input STFT --ckpt model.pt \
    --preprocess "창별 RMS 정규화 · STFT n256/h128" \
    --arch "CNN2D 5블록 · width 48" \
    --loss CrossEntropy --optim "AdamW · OneCycle" \
    --epochs 8 --batch 128 --lr 3e-4

    row,pred 두 열이면 됩니다. 전처리·구조·학습 설정을 같이 주면 리더보드에서 행을 눌러 펼쳐 볼 수 있습니다. 사전학습을 했다면 --pretrain, 예측 전에 타깃 데이터로 적응한다면 --adapt 를 붙이면 배지가 달립니다. 사용법 자세히 보기

    채점 규약

    순위
    네 시나리오의 평균으로 매깁니다.
    집계
    창 단위로 내면 채점기가 주행 단위 다수결로 묶습니다.
    FNR
    고장을 정상이라 놓친 주행 비율(%). 안전상 가장 위험한 오류입니다.
    FPR
    정상을 고장이라 부른 주행 비율(%).
    FNR+FPR
    두 오류를 더한 값. 낮을수록 좋습니다.
